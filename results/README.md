# Results

- `runs.csv` — one row appended per run by the training script. Never edit by hand;
  never delete failed or invalid runs (mark them in `status` / `notes`).
- `plots/` — generated by the analysis script.
- `profiles/` — profiler summary tables and timeline screenshots
  (raw trace JSON is git-ignored because of size).

## `runs.csv` schema

| Column           | Meaning |
|------------------|---------|
| run_id           | Unique id (e.g. `<slurm_job_id>_<index>`) |
| timestamp        | ISO 8601 start time |
| job              | Experiment group: A, B, C, D, E, opt, final |
| experiment       | Short label, e.g. `baseline_fp32`, `seqlen_512`, `ddp_p2p_off`, `cpu_threads_16` |
| slurm_job_id     | `$SLURM_JOB_ID` |
| nodes            | Node names (`$SLURM_JOB_NODELIST`) |
| device           | `cuda` or `cpu` |
| gpu_model        | e.g. from `torch.cuda.get_device_name()`; empty for CPU |
| world_size       | Number of DDP processes |
| num_threads      | `torch.get_num_threads()` (CPU runs) |
| n_layer          | |
| n_embd           | |
| n_head           | |
| n_params         | |
| seq_len          | |
| global_batch     | Sequences per optimizer step (fixed at 64 for DDP comparisons) |
| precision        | `fp32` or `bf16` |
| seed             | |
| steps            | Total steps run |
| warmup_steps     | Steps excluded from timing (~20) |
| nccl_p2p_disable | 0/1 |
| t_data_ms        | Median per-step data-loading time (post warm-up) |
| t_fwd_bwd_ms     | Median forward+backward time |
| t_optim_ms       | Median optimizer time |
| t_comm_ms        | Median gradient-communication time (0 for single process) |
| t_step_ms        | Median total step time |
| tokens_per_s     | global_batch × seq_len / step time |
| peak_mem_mb      | Peak GPU memory (or RSS for CPU) |
| val_loss_500     | Validation loss after 500 steps (empty if fewer steps) |
| final_val_loss   | |
| valid            | Correctness rule result vs. single-GPU fp32 baseline: `yes` / `no` / `n/a` |
| status           | `ok`, `failed`, `SKIPPED` |
| notes            | Free text (reason for SKIPPED/failed, etc.) |
